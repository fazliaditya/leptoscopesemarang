# LeptoScope — Refined UI

Revisi antarmuka:

- Halaman awal disusun ulang: berita/konteks kesehatan tampil sebelum pengantar WebGIS.
- Kartu berita menggunakan ilustrasi berlisensi terbuka dari Wikimedia Commons dan tautan berita resmi WHO/Kemenkes.
- Tampilan dibuat lebih elegan: warna off-white, navy, dan teal; tipografi lebih tenang; grid dan spacing diperbaiki.
- Preview homepage memakai OpenStreetMap.
- Map workspace dirapikan dengan panel analisis yang lebih kompak.
- Panel Layer & Basemap ditata ulang menjadi tiga bagian: layer analisis, basemap, dan legenda.
- Basemap utama diubah menjadi OpenStreetMap Standard.
- Basemap kedua memakai Esri World Imagery sebagai citra satelit.
- Ditambahkan toggle Batas Kecamatan terpisah dari poligon Prioritas Risiko.
- Fasilitas kesehatan tetap tersedia sebagai overlay opsional.
- Tata letak mobile untuk panel analisis dan layer menggunakan bottom sheet yang lebih ringkas.
