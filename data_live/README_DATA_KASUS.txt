PEMBARUAN DATA KASUS LEPTOSCOPE v6.2

Cara yang direkomendasikan:
1. Buka WebGIS > mode Eksperimental.
2. Klik "Unduh template".
3. Isi kolom case_count.
4. Klik "Unggah Excel / CSV".
5. Periksa hasil validasi dan preview.
6. Klik "Terapkan & perbarui peta".

Aturan:
- 0 = nihil kasus terverifikasi.
- Kosong = data belum diterima.
- Empat bulan kalender lengkap terakhir harus mencakup 16 kecamatan agar dipakai model.
- Bulan berjalan boleh parsial dan hanya dipakai untuk monitoring sementara.
- Upload ulang pada kecamatan-bulan yang sama akan mengganti nilai lama, bukan menjumlahkannya.
- Window periode bergeser otomatis saat bulan berganti.

File aktif yang dibaca backend: data_live/kasus_terbaru.csv
Template statis di folder ini mengikuti periode saat rilis; tombol "Unduh template" di web selalu membuat template sesuai tanggal sistem saat dibuka.
